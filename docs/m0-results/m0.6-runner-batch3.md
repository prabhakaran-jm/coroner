## Frozen interface note (Phase 1 gate)

Experiments A, B and C (`exp_a.py`, `exp_b.py`, `exp_c.py`) are written against `base.py` and must not edit it.
Where this note and the code differ, the code is authoritative.

### Plug-in pattern

Each experiment module defines:

```python
def run(ctx: ExperimentContext) -> ExperimentResult:
    return run_experiment(ctx, _body)

def _body(ctx: ExperimentContext, pre: PreambleResult) -> ExperimentResult:
    ...  # drive the leak, crash/kill/OOM, poll inspect, record, then finalize_run(...)
```

`run_experiment(ctx, body)` runs the preamble, calls the body, and converts every `ExperimentError` (and any
unexpected error) into a failed or aborted manifest plus an `ExperimentResult`. The body ends with
`finalize_run(...)` or raises `ExperimentError(code, message)`. The body never prints and never calls `sys.exit`.
The CLI prints `ExperimentResult.line` and exits with `ExperimentResult.exit_code`.

### Exit codes

| Code | Meaning |
| --- | --- |
| 0 | Passed. |
| 1 | Failed or aborted after a run id exists. A readable manifest exists (`manifest_path`), unless the manifest itself could not be written (`manifest_path is None`, the message says why). |
| 2 | Docker unavailable, invalid arguments, or environment error before a run id exists (`PreRunError`): `run_id is None`, no manifest. Also `docker_compose_failed`, which happens after the run id exists: exit 2 and a manifest IS written (outcome `aborted`). |

`FAILURE_TABLE` maps failure code to (manifest outcome, exit code). Pre-run codes (`docker_unavailable`,
`invalid_arguments`, `environment_error`) use outcome `not_started`. Aborted (exit 1): `collector_unhealthy`,
`collector_storage_unhealthy`, `clock_offset_unavailable`, `run_id_collision`, `invalid_container_id`,
`demo_app_failed_to_start`, `no_baseline_sample`, `leak_failed`, `interrupted`, `internal_error`, `run_incomplete`.
Failed (exit 1): `timeout`, `unexpected_exit_code`, `oomkilled_mismatch`, `docker_inspect_failed`,
`evidence_unavailable`, `collector_survival_failed`, `no_memory_growth_observed`, `no_precrash_evidence`,
`sample_captured_after_kill`, `durability_mismatch`, `shutdown_handler_records_found`, `termination_post_failed`,
`check_failed`, `manifest_write_failed`, `docker_kill_failed`, `crash_request_failed`. An unknown code defaults to failed, exit 1.

### ExperimentContext

Caller-supplied fields (constructor arguments):

| Field | Type / default |
| --- | --- |
| `experiment` | `"A"`, `"B"` or `"C"` (upper-cased; anything else raises `ValueError`) |
| `docker` | `DockerPort` |
| `collector` | `CollectorClient` |
| `runs_dir` | `Path | str` |
| `mem_limit` | `str | None`, default `"128m"`; `None` = not passed to compose |
| `leak_chunk_bytes` | `int`, default 4194304; valid 1..104857600 |
| `sample_interval_ms` | `int | None`, default `None`; valid 100..60000 |
| `demo_url` | `str`, default `http://127.0.0.1:8080` |
| `http` | `Transport | None`; default `urllib_transport()` |
| `wall_clock` | `Callable[[], datetime]`, default UTC now (aware) |
| `monotonic` | `Callable[[], float]`, default `time.monotonic` |
| `sleep` | `Callable[[float], None]`, default `time.sleep` |
| `rand_hex` | `Callable[[], str] | None`, 8 lowercase hex for the run id; `None` = secrets |

Preamble-filled, read-only for experiments: `run_id`, `run_dir`, `manifest`, `mem_limit_bytes`, `container_id`,
`durability`, `clock_offset_ms`, `clock_offset_uncertainty_ms`.
Methods: `now()` (aware UTC, truncated to ms, from `wall_clock`) and `stamp()` (`format_utc_ms(now())`).
Sign convention: `clock_offset_ms` = server time minus host midpoint. Host-equivalent time = container time minus offset
(`host_time()`, `classify_b_samples(..., clock_offset_ms=ctx.clock_offset_ms)`).

`ctx.manifest` is the live `RunManifest`. Experiments may mutate `ctx.manifest.extra[...]`, `.container_state`,
`.evidence`, `.termination_description`, then persist with `write_phase`.

### PreambleResult and ExperimentResult

`PreambleResult` (frozen): `run_id`, `container_id` (64 lowercase hex), `clock_offset_ms`,
`clock_offset_uncertainty_ms`, `durability` (`str | None`), `demo_health` (`dict | None`), `baseline`
(`EvidenceBundle`), `first_sample` (`SampleView`).

`ExperimentResult` (frozen): `exit_code`, `outcome` (`passed` | `failed` | `aborted` | `not_started`), `experiment`,
`run_id` (`str | None`), `manifest_path` (`Path | None`), `message`, `failure` (`Failure | None`, default `None`),
`checks` (`tuple[Check, ...]`, default `()`), `phase` (`str | None`, default `None`). Property `line`:
`"Experiment <X> <run id or -> : <OUTCOME> - <message>"`.

### Entry points

- `run_experiment(ctx, body) -> ExperimentResult`
- `run_preamble(ctx) -> PreambleResult`: raises `PreRunError` before a run id exists, otherwise `ExperimentError`.
- `finalize_run(ctx, *, evaluation: Evaluation | None = None, extra_checks: Sequence[Check] = ()) -> ExperimentResult`.
  Passes only when at least one check exists, the evaluation passed and every check passed. Otherwise outcome
  `failed`, exit 1, failure from `failure_for_checks`.
- `fail_run(ctx, error) -> ExperimentResult`: writes the failure manifest (phase `failed:<code>`), keeps evidence so far.
- `pre_run_result(ctx, error) -> ExperimentResult`: no manifest.

### Manifest helpers

- `write_phase(ctx, phase, *, updates=None) -> Path`: atomic rewrite of `runs/<run_id>/manifest.json`. Applies
  `updates` to `extra`, sets `extra["phase"]`, appends `{"name", "time"}` to `extra["phases"]`, sets `end_time`.
  Raises `ManifestWriteError`. The phase helpers below call it themselves.
- `record_time(ctx, key, instant) -> None`: `extra["times"][key]`, key is `crash_request_time` or `sigkill_sent_time`. No write.
- `host_time(ctx, container_time) -> datetime`: `container_time - clock_offset_ms`.
- `MANIFEST_EXTRA_KEYS`: every manifest carries exactly these keys in `extra` (null or empty when not applicable):
  `phase`, `phases`, `finished`, `container_id`, `container_finished_at`, `container_left_running`,
  `docker_inspect_path`, `container_state_problems`, `collector`, `clock_offset_ms`, `clock_offset_uncertainty_ms`,
  `memory`, `highest_rss_bytes`, `leak`, `times`, `collector_health`, `termination`, `checks`, `diagnostics`,
  `sampling_limitations`, `sample_timing`, `evidence_summary`, `limitations`.
- `failure_for_checks(checks, message=None) -> Failure`: the first failed check decides the code, via
  `CHECK_FAILURE_CODES` (exact names) then `CHECK_FAILURE_PREFIXES` (`exit_code` -> `unexpected_exit_code`,
  `oom_killed` -> `oomkilled_mismatch`, `at_least_one_sample` -> `no_precrash_evidence`); otherwise `check_failed`.
- `checks_to_dicts(checks) -> list[dict]`: `{"name", "passed"[, "detail"]}`.

The initial manifest is written with outcome `aborted`, failure code `run_incomplete` and `extra["finished"] = False`.
`finalize_run` or `fail_run` replaces it and sets `finished` to True. `extra["times"]` starts as
`{"crash_request_time": None, "sigkill_sent_time": None}`. `container_left_running` defaults to False.
`sample_timing` is set only by B (`ctx.manifest.extra["sample_timing"] = timing.to_dict()`); `memory`, `diagnostics`
and `sampling_limitations` are set only by C (see `record_memory`).

### Inspect and state conversion

- `read_inspect(result: InspectResult) -> InspectReading`: never raises, never fabricates. A missing or ill-typed field is
  None and named in `.problems`. `.complete` requires `Id` (64 lowercase hex), `State.Status`, `State.OOMKilled`
  (bool), `State.ExitCode` (int, not bool), `HostConfig.Memory` (int >= 0) and an aware inspect time.
  `InspectReading` fields: `inspect_time`, `id`, `status`, `oom_killed`, `exit_code`, `memory`, `finished_at`
  (None when absent, unparseable or the zero value), `finished_at_raw`, `problems`, `result` (the `InspectResult`,
  for the raw bytes). Properties: `complete`, `excerpt` (raises `IncompleteInspectError`).
- `to_eval_state(reading) -> evaluate.ContainerState`: raises `IncompleteInspectError` when incomplete.
- `to_manifest_state(reading, raw_inspect_path) -> manifest.ContainerState`: same.
- `to_inspect_record(reading, raw_inspect_path | None) -> evaluate.InspectRecord`: never raises; missing fields stay None.
- `to_termination_state(reading) -> {"status", "exit_code", "oom_killed"}`: raises when incomplete.
- `derive_cause_label(experiment, state: InspectReading | EvalContainerState | None) -> str`:
  `controlled_fatal_process_exit` (A), `sigkill_sent_by_runner` (B), `docker_oom_kill` (C), only when the observed state
  equals that experiment's expected state with status `exited`; otherwise `unknown` (`CAUSE_UNKNOWN`).
- `record_inspect(ctx, reading, *, save_raw=True) -> manifest.ContainerState | None`: saves the raw bytes unchanged to
  `runs/<run_id>/docker_inspect.json` (also when the reading is incomplete), sets `ctx.manifest.container_state`
  (None when incomplete), sets `extra["docker_inspect_path"]`, `extra["container_finished_at"]`,
  `extra["container_state_problems"]`, then `write_phase("container_inspected")`. Raises `InspectFailed` if the raw
  file cannot be saved.
- `inspect_once(ctx, container_id) -> InspectReading`: raises `InspectFailed` on a Docker error.
- `poll_inspect(ctx, container_id, until, interval_s, timeout_s) -> PollResult`: calls `ctx.docker.inspect`,
  `read_inspect`, and `until(reading)` only for complete readings. Sleeps via `ctx.sleep`, measures with
  `ctx.monotonic`, tries once more at the deadline. `DockerError`/`ValueError` are remembered in `PollResult.error`
  and polling continues. `PollResult`: `outcome` (`matched` | `timeout` | `inspect_failed`; `inspect_failed` means no
  complete reading was ever obtained), `reading` (last, or the matching one), `result`, `attempts`, `elapsed_s`,
  `error`; property `matched`.
- Predicates on `InspectReading.status`: `until_exited`, `until_running`, `until_not_running` (status not None and not `running`).
- Aliases: `EvalContainerState` = `evaluate.ContainerState`, `ManifestContainerState` = `manifest.ContainerState`.
  Both are imported names in `base.py`, not listed in `__all__`.
- No helper defaults or invents a missing value.

### Leak driver and Demo App

`drive_leak(ctx, *, chunk_bytes=None, min_duration_s=5.0, max_duration_s=None, interval_s=1.0, request_timeout_s=5.0,
stop_when=None, abort_on_failure=True) -> LeakResult`

- POSTs `{demo_url}/leak?bytes=<chunk>` every `interval_s` (slot-based, first call immediately). A reply slower than
  `request_timeout_s` counts as a failure.
- Stop reasons: `complete` (`min_duration_s` elapsed since the first call; A and B), `stopped` (`stop_when()` true,
  checked before each request), `timeout` (`max_duration_s` elapsed; C), `request_failed`.
- With `abort_on_failure=True` (A and B) a failed request raises `ExperimentError("leak_failed")` after the leak block
  is recorded, so the caller never reaches crash or kill. C passes `abort_on_failure=False` and reads `LeakResult.reason`.
- At least one of `min_duration_s`, `max_duration_s`, `stop_when` is required, and `chunk_bytes` must be an int in
  1..104857600 (otherwise `ValueError`).
- Records `extra["leak"]` and `write_phase("leak_finished" | "leak_failed")`.
- `LeakResult`: `chunk_bytes`, `requests` (`tuple[LeakRequestRecord, ...]`), `cumulative_bytes` (sum acknowledged by
  HTTP 200), `reason`, `error`, `first_call_time`, `last_response_time`, `last_response_mono`, `duration_s`;
  properties `ok` (reason == `complete`), `request_count`; method `block()`.
  `LeakRequestRecord`: `index`, `sent_time`, `http_status`, `elapsed_s`, `ok`, `error`, `retained_bytes_total`.
- `post_leak_wait_s(interval_ms: int | None) -> float`: `max(1.0, 1.5 * interval, 1.0 + interval + 0.25)` seconds
  (interval defaults to 500 ms when None).
- `wait_after_leak(ctx, leak) -> float`: sleeps until `post_leak_wait_s` after the last response; returns seconds slept.
- `demo_request(ctx, method, path, *, timeout_s) -> HttpResponse`: raises `DemoRequestError` when there is no response
  (for A this is the dropped `POST /crash` connection).

### Evidence, termination, survival

- `read_evidence_bundle(ctx) -> EvidenceBundle`: GETs the evidence through the Collector and parses it with the
  Evidence_Reader. Raises `EvidenceUnavailable`. No manifest change.
- `fetch_evidence(ctx) -> EvidenceBundle`: the above, plus host copy `runs/<run_id>/evidence.jsonl`,
  `manifest.evidence`, `extra["evidence_summary"]`, `write_phase("evidence_fetched")`.
  `EvidenceBundle`: `raw`, `result`, `summary`, `samples` (capture-time order), `durability_levels`, `fetched_at`;
  properties `record_count`, `sample_count`.
- `post_termination(ctx, reading, *, cause_label=None, note=None) -> TerminationPost`: POSTs
  `/v1/runs/<id>/termination` with `source`, `observed_time` (the inspect time), `container_state`, `cause_label`
  (default `derive_cause_label`), `note`. Never raises for HTTP trouble. An incomplete reading is not posted (`ok` False).
  Records `extra["termination"]`, `write_phase("termination_posted")`. `TerminationPost`: `ok`, `http_status`,
  `cause_label`, `payload`, `error`; property `check` (`termination_recorded`). Pass `post.check` in `extra_checks`.
- `verify_collector_survival(ctx, within_s=5.0) -> SurvivalResult`: GET `/healthz` until HTTP 200 with
  `storage_ok is True` within `within_s`. A 200 with storage not True fails at once; no response or non-200 is retried
  every 0.5 s inside the window. A healthy reply later than `within_s` fails and is returned as `http_status None`.
  Records `extra["collector_health"]` and `write_phase("collector_survival")`. `SurvivalResult`: `ok`, `health`
  (`HealthResult`), `elapsed_s`, `detail`; property `check` (`collector_survival`).

### Check helpers

- `growth_check(samples, leak, clock_offset_ms, *, fraction=0.5, min_after_s=1.0, name="memory_growth_matches_leak") -> Check`
  (A and B, Requirement 7.4).
- `durability_check(ctx, bundle) -> Check` (`durability_matches_run_metadata`).
- `check_no_shutdown_records(bundle) -> Check` (`no_shutdown_handler_records`).
- `check_sample_captured_before(name, samples, instant, clock_offset_ms) -> Check`.
- `memory_limit_check(ctx, reading) -> Check` (`memory_limit_matches_host_config`: `parse_mem_size(mem_limit)` equals `HostConfig.Memory`).
- `first_rss_bytes(samples)` and `highest_rss_bytes(samples)`: `int | None`, null RSS skipped, never 0.
- `record_memory(ctx, samples, *, reading=None, include_block) -> None`: sets `extra["highest_rss_bytes"]`; with
  `include_block` (C) also `extra["memory"]` = `{configured_limit_bytes, memory_limit_bytes, highest_rss_bytes, first_rss_bytes}`. No write.

### Error types

- `ExperimentError(code, message, *, outcome=None, exit_code=None)`: attributes `code`, `message`, `outcome`
  (`failed` | `aborted`), `exit_code`, property `failure` (`Failure`).
- `PreRunError(code, message)`: no run id, no manifest, exit 2.
- `ManifestWriteError(message)`: code `manifest_write_failed`.
- `EvidenceUnavailable(message, http_status=None)`: code `evidence_unavailable`; attribute `http_status`.
- `InspectFailed(message)`: code `docker_inspect_failed`.
- `DemoRequestError(Exception)`: a Demo_App request got no response.
- `IncompleteInspectError(ValueError)`: attribute `problems: tuple[str, ...]`.

## Manifest representability

`RunManifest` core fields: `experiment`, `run_id`, `outcome`, `start_time`, `end_time`, `durability_level`,
`termination_description`, `expected`, `failure`, `container_state`, `evidence`, and `extra` (written at the top level
and preserved across a read/write cycle).

| Item | Representable? | Where |
| --- | --- | --- |
| Run id | Core | `RunManifest.run_id` |
| Experiment | Core | `RunManifest.experiment` |
| Failure / outcome (passed, failed, aborted) | Core | `RunManifest.outcome`, `RunManifest.failure` (`Failure(code, message)`) |
| Container state (complete inspect) | Core | `RunManifest.container_state` (`status`, `exit_code`, `oom_killed`, `container_id`, `host_config_memory_bytes`, `inspect_time`, `raw_inspect_path`, `raw_inspect_excerpt`) |
| Inspect evidence (raw output) | Core path plus file | `container_state.raw_inspect_path`; file `runs/<run_id>/docker_inspect.json`; also `extra["docker_inspect_path"]` |
| Collector readiness | Extra | `extra["collector"]`, `extra["collector_health"]`, `extra["clock_offset_ms"]`, `extra["clock_offset_uncertainty_ms"]` |
| Evidence summary | Core plus extra | `RunManifest.evidence` (`EvidenceRef`), `extra["evidence_summary"]` |
| Checks | Extra | `extra["checks"]` (list of `{name, passed[, detail]}`) |
| `sample_timing` | Extra | `extra["sample_timing"]` (B only) |
| Diagnostics | Extra | `extra["diagnostics"]` (C only) |
| `sampling_limitations` | Extra | `extra["sampling_limitations"]` (C only) |
| `container_left_running` | Extra | `extra["container_left_running"]` |

Not representable as a core field (handled through `extra`; `manifest.py` is unchanged):

| Item | Why not core | Handling |
| --- | --- | --- |
| Outcome `running` | Core outcomes are `passed`, `failed`, `aborted` (plus `not_started`, which is never written) | The initial manifest is written as `aborted` with failure code `run_incomplete` and `extra["finished"] = False`. `finalize_run` or `fail_run` replaces it. |
| `State.FinishedAt` in `InspectExcerpt` | `InspectExcerpt` holds exactly five fields (`Id`, `State.Status`, `State.OOMKilled`, `State.ExitCode`, `HostConfig.Memory`) | Stored in `extra["container_finished_at"]`; the raw file keeps the original. |
| `container_state` when inspect is incomplete | `ContainerState` requires every field | `container_state` is `null`, and `extra["container_state_problems"]` lists what was missing. The raw bytes are still saved. |

## Contract notes (resolved)

1. **Initial manifest.** It is written as outcome `aborted` with failure `run_incomplete` and `finished` False, because `RunManifest` has no `running` outcome. A crash of the runner itself leaves that manifest. Confirmed by tests: the placeholder is the only thing on disk before the run ends, and both `finalize_run` (success) and `fail_run` (failure) replace it (`run_incomplete` is absent from the final manifest; `finished` is True).
2. **Experiment B, `State.FinishedAt` is optional.** It is stored in `extra["container_finished_at"]` (the `InspectExcerpt` has five fixed fields). It is not a verdict condition: there is no `container_finished_at_recorded` check (it appears only in negative assertions in the tests), and the evaluator's seven checks are untouched. When `FinishedAt` is missing, unreadable or the zero value, `finished_at` is None, `classify_b_samples` skips the after_container_stop analysis, nothing is fabricated, `sample_timing["after_container_stop_analysis"]` is `"unavailable"` (`"available"` otherwise), `container_finished_at` is null, and the limitation `FINISHED_AT_LIMITATION` is added to `extra["limitations"]`.
3. **Experiment C, three-way classification of a leak that does not end in an exit.** `LEAK_FAILURE_SETTLE_S = 3.0`.
   - Deadline reached (120 s since the first leak call) with the container still running: failure `timeout`, `container_left_running` True, container never stopped or killed.
   - A leak request failed and the container is still running after the 3.0 s settle window: failure `leak_failed` (aborted), `container_left_running` True.
   - A leak request failed because the container terminated (for example the OOM kill itself): the run continues to the normal Docker-grounded evaluation (`evaluate_experiment_c` on `docker inspect`). Nothing is synthesized: `exp_c.py` has no `kill(` call, no `/crash` call, and no literal `exit_code` or `OOMKilled` assignment (grep confirmed; the only matches are docstring and comment text).
4. **Experiment A, `/crash` replies.** A dropped connection is the expected outcome and the run proceeds to the 30 s inspect poll. A completed HTTP response to `POST /crash` (any status) fails at once with `crash_request_failed` (failed, exit 1; entry in `FAILURE_TABLE`). The runner takes one best-effort immediate inspect reading, records it, and appends a statement to `extra["limitations"]` saying a controlled fatal exit was not demonstrated and that the termination description is the planned one, not an observed one.
5. **`docker_kill_failed`** (Experiment B, `docker kill` raised) is in `FAILURE_TABLE` as failed, exit 1.
6. Failure codes after a run id exists are always written to a manifest; `docker_compose_failed` is the one such code with exit 2.

## Limitations

- No live Docker, Compose, Collector or Demo_App was used. Every Docker, HTTP and clock interaction is a scripted fake.
- No genuine OOM kill was produced. Experiment C's pass in these tests shows the control flow and the evaluation of Docker's reported values, not that the kernel kills the container. Task 7.5 holds that proof.
- No real `SIGKILL`, `/crash` or sockets were used (the guard run confirms none were attempted).
- The `crash_request_failed` path covers only a completed `/crash` response. A Demo_App that answers `/crash` and then still exits is reported as a failure even though the process may have exited; the immediate inspect reading is recorded but is not used for the verdict.
- The command-line entry point (argument parsing, printing `ExperimentResult.line`, exit codes) is Task 6.18 and is not part of this batch.
- Timing in B and C comes from a fake monotonic clock; the 250 ms tolerance is unchanged.
